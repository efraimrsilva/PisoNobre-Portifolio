# 🪵 Raspagem e Aplicação de Sinteco WC – Restauração de Pisos de Madeira

## 📖 Sobre o Projeto

O **Raspagem e Aplicação de Sinteco WC** é um site institucional para apresentação de serviços profissionais de raspagem, revitalização, calafetação e aplicação de sinteco em pisos de madeira.

O projeto foi pensado para transmitir confiança, destacar mais de 20 anos de experiência e facilitar o contato de clientes residenciais e comerciais pelo WhatsApp. A experiência reúne vídeos de resultados, uma galeria interativa e informações claras sobre o processo de restauração.

## 📷 Preview

Execute o projeto localmente e acesse [http://localhost:3000](http://localhost:3000) para visualizar a página.

## 🛠️ Tecnologias Utilizadas

- **Next.js 16** → Framework React para a aplicação
- **React 19** → Construção da interface interativa
- **TypeScript** → Tipagem e maior segurança no desenvolvimento
- **Tailwind CSS 4** → Estilização responsiva da interface
- **Day.js** → Atualização dinâmica do ano no rodapé
- **Lucide React** e **React Icons** → Ícones de interface, WhatsApp e Instagram
- **YouTube (privacy-enhanced mode)** → Vídeos de transformação incorporados

## ⚙️ Recursos Técnicos

- **Responsividade**
  - Interface preparada para desktop, tablet e celular
  - Menu móvel, grids adaptativos e galeria de miniaturas com rolagem horizontal

- **Performance e mídia**
  - Imagens locais otimizadas pelo componente `next/image`
  - Hero em tela cheia com imagem local
  - Vídeos em autoplay, sem áudio e em loop

- **Acessibilidade e navegação**
  - Rótulos acessíveis nos botões e ações flutuantes
  - Foco visível em elementos interativos
  - Navegação por âncoras entre as seções do site

## 🎨 Principais Funcionalidades

### 🔝 Cabeçalho e navegação

- Cabeçalho fixo e translúcido sobre todas as seções
- Navegação por serviços, resultados, processo e dúvidas
- Menu hambúrguer adaptado para telas menores

### 💡 Hero Section

- Mensagem de impacto sobre restauração de pisos de madeira
- Imagem de fundo local em largura total
- Chamadas para ação diretas para WhatsApp e resultados
- Destaque para experiência, atendimento residencial/comercial e acabamento

### 🛎️ Serviços

- Raspagem de tacos e assoalhos
- Aplicação de qualquer tipo de sinteco
- Revitalização de pisos de madeira
- Calafetação e correções de frestas, juntas e rachaduras

### 🎞️ Transformações reais

- Três vídeos do YouTube reproduzidos automaticamente, sem som e em loop
- Galeria com 14 fotos de projetos
- Troca automática de imagem a cada 6 segundos
- Fade suave entre imagens e navegação manual pelas miniaturas
- Miniatura ativa centralizada na faixa horizontal, sem movimentar a página verticalmente

### 📋 Processo e dúvidas

- Etapas do serviço, da avaliação à finalização
- FAQ com orientações sobre prazo, poeira, proteção de itens e orçamento

### 📬 Contato

- Links diretos para WhatsApp, com incentivo ao envio de áudio
- Botões flutuantes de WhatsApp e Instagram
- Rodapé com telefone, área de atendimento, links rápidos e ano dinâmico

## 🚀 Como Executar o Projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/efraimrsilva/Sinteco-Portifolio.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd Sinteco-Portifolio
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o ambiente de desenvolvimento:

   ```bash
   npm run dev
   ```

5. Abra [http://localhost:3000](http://localhost:3000) no navegador.

## 📦 Build de Produção

Para gerar a versão otimizada:

```bash
npm run build
```

Para iniciar a aplicação compilada:

```bash
npm run start
```
